Section 6

What this proof does not do

A page that only flatters its own argument is not worth reading. Three things above are load-bearing and deserve to be said out loud.

caveat 1 · existence

Uniqueness is not existence

The proof multiplies by and differentiates it. So it assumes a function with this property already exists. What is established is: there is at most one solution with .

Producing one from nothing is a different job, done by the power series — which converges everywhere and can be differentiated term by term. Existence and uniqueness are two theorems, and this page owns only the second.
