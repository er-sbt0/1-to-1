Cantor Space is Compact

Tychonoff's theorem says an arbitrary product of compact spaces is compact. The cleanest place to feel why is Cantor space — countably many copies of the two‑point set , which is the same thing as the set of infinite paths through a binary tree. The tree & its coordinates

Every node is a finite binary word — an address. The root is the empty word . Going down, each edge fixes one more coordinate to 0 (left) or 1 (right). An infinite path from the root fixes all coordinates — that is a single point of Cantor space.

Basic open sets = cylinders

A basic open set in the product topology constrains only finitely many coordinates and leaves the rest free. Fix a finite prefix ; the open set is every path that starts with it — the whole subtree hanging below that node.

Why it stays compact

Compactness ≈ every infinite sequence of points has a convergent subsequence. Drop a cloud of points, then run the pigeonhole descent: one child of each node must hold infinitely many of them (with only two children, they can't split a finite pile). Follow that child forever — the path you trace is the limit point.

How the picture proves the theorem

Each visual above maps onto one moving part of the compactness argument.
01 · THE FACTORS

Each coordinate is compact

A point is a function . Coordinate lives in the two‑point discrete space , which is finite and therefore compact. These are the humble pieces Tychonoff glues together.

02 · THE TOPOLOGY

Open sets fix finitely much

The product topology is generated by cylinders: fix finitely many coordinates, leave the rest free. In the tree these are exactly the subtrees below a finite node. This "finiteness" is the whole subtlety of the product topology — and why the theorem isn't obvious.

03 · THE PROOF

Pigeonhole builds a limit

Given infinitely many points, some child of the root holds infinitely many (König's lemma / pigeonhole). Recurse forever; the coordinates you pick out assemble into a single limit path. That convergent subsequence is sequential compactness, and for this metrizable product it delivers Tychonoff directly.
